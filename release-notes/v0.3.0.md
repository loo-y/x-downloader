# x-downloader v0.3.0

- 将 X、YouTube 与 MissAV 提升为统一的结构化 Python API。
- 新增稳定请求/结果类型、结构化错误、进度回调和取消检查。
- CLI 改为公共 API 的兼容包装。
- MissAV 支持显式 `/usr/bin/chromium`、无头模式和临时 Profile，适用于隔离容器。
- 新增 NestDeck stdin JSON / stdout NDJSON runner。
- 运行依赖锁定 yt-dlp 2026.08.19、yt-dlp-ejs 0.8.0 与 websocket-client 1.8.0。
