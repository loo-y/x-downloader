# x-downloader v0.3.1

- `FormatOption` 新增 `format_kind`、音视频编码、音视频码率、尺寸、帧率和文件大小字段。
- `DownloadRequest` 新增 `selection_mode`，兼容旧 `audio_only` 输入。
- `VIDEO_ONLY` 格式在默认 `VIDEO_WITH_AUDIO` 模式下会自动追加 `+bestaudio/best` 合并最佳音频。
- 显式 `VIDEO_ONLY` 模式支持原样下载无声视频流。
- `AUDIO_ONLY` 模式会优先使用调用方指定的音频 `format_id`，不再忽略具体音频流。
- 下载完成后通过 `ffprobe` 返回实际轨道、编码、尺寸、时长与文件大小。
- NestDeck runner 为结构化输出补充 camelCase 字段别名，便于调用方平滑迁移。
- 新增格式分类、选择模式、ffprobe 映射和 runner 序列化测试。
