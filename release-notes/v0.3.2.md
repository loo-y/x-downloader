# x-downloader v0.3.2

这是对 `v0.3.1` 的兼容性修复版本。

## 修复

- 修复 `resolve_media(ResolveRequest(...))` 在共享 yt-dlp options 构建阶段错误读取 `selection_mode`，导致 CLI 与 NestDeck 链接识别抛出 `AttributeError` 的问题。
- 保持解析与下载职责分离：`ResolveRequest` 不包含下载规格策略，只有 `DownloadRequest` 才参与格式选择。
- 增加回归测试，锁定普通 ResolveRequest 可以完成 options 构建而不访问下载专用字段。

## 服务端集成

- NestDeck 应固定安装 `x_downloader-0.3.2-py3-none-any.whl` 并校验发布资产 SHA-256。
- 不需要改变 `v0.3.1` 已定义的 `selection_mode`、格式语义或 NDJSON runner 协议。

## 验证

- `tests/test_api.py`：6/6 通过。
- 全部 24 个测试均到达通过断言；Windows 测试进程仍可能因既有后台句柄延迟退出。
- 按用户要求，本次发布前没有执行真实网络下载。
